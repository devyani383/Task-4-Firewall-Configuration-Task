# Firewall Configuration Task

## Objective

Configure and test basic firewall rules using Windows Defender Firewall on Windows 11.

## Tool Used

Windows Defender Firewall with Advanced Security

## Steps Performed

1. Opened Windows Defender Firewall with Advanced Security.
2. Viewed existing Inbound Rules.
3. Created a new Inbound Rule to block TCP Port 23 (Telnet).
4. Verified that the rule was successfully created.
5. Deleted the rule to restore the original firewall configuration.

## Why Port 23 Was Blocked

Port 23 is used by Telnet, which transmits data in plain text and is considered insecure.

## Outcome

Successfully learned basic firewall management, including creating, verifying, and removing firewall rules. Also gained an understanding of how firewalls filter network traffic to improve security.
